# Инструкция по запуску оценки качества обезличивания

Harness: `data/natasha_training/eval_2x2.py`
Датасет: `data/natasha_training/test/test.jsonl` (150 примеров, held-out от train).

## Что это

Прогоняет модуль на held-out наборе и считает метрики: strict/relaxed,
Micro/Macro, Precision/Recall/F2, LeakRate, время. Оценивается **одна
конфигурация** — та модель PERSON, что сейчас загружена (определяется
переменной `PERSON_MODEL_DIR`).

> **История.** Раньше это был факторный план 2×2: два фактора — предобработка
> текста через GramLynx и дообучение модели. Предобработка **отклонена** по
> результатам замеров (×4-5 латентности при нулевом выигрыше по приватности) и
> удалена из проекта вместе со всем prep-кодом. Осталась одна ось — модель.
> Имя файла `eval_2x2` сохранено историческим, чтобы не рвать ссылки.

Все команды — из **корня проекта** (`ANONIMIZATION_MODULE`).

---

## Запуск

```bash
# продакшн-модель (дообученный ruBERT)
PERSON_MODEL_DIR=models/person_ruBERT python3 data/natasha_training/eval_2x2.py -K 5 --warmup 1
```

Параметры:

- `--label` — как подписать конфигурацию в результате (по умолчанию определяется
  по наличию модели).
- `--out` — куда писать JSON (по умолчанию `eval_2x2_results.json`).
- `-K` — сколько повторов для замера времени (по умолчанию 5).
- `--warmup` — сколько первых прогонов выбросить как прогрев (по умолчанию 1).
- `--no-time` — не мерить время (быстрее, только качество).

Результат печатается в консоль и пишется в JSON.

## Сравнение двух моделей (базовая vs дообученная)

Модель выбирается один раз при импорте модуля, поэтому одна и та же программа не
может «переключать» её на лету. Сравнение делается **двумя прогонами** в разные
файлы, затем результаты сводятся:

```bash
# базовая модель (указать путь к ней в PERSON_MODEL_DIR)
PERSON_MODEL_DIR=<путь-к-базовой-модели> \
    python3 data/natasha_training/eval_2x2.py --label "базовая" --out /tmp/base.json

# наша дообученная
PERSON_MODEL_DIR=models/person_ruBERT \
    python3 data/natasha_training/eval_2x2.py --label "дообученная" --out /tmp/trained.json
```

> Без `PERSON_MODEL_DIR` модель PERSON не загружается — ФИО не распознаются
> вообще, и LeakRate по именам будет ненулевым. Это ожидаемо: замер «без модели»
> показывает вклад модели, но продакшн-конфигурация — всегда с моделью.

## Как читать результат

- **Recall / LeakRate** — главные: пропуск ПДн = утечка. Высокий Recall, LeakRate
  около 0% = хорошо.
- **Precision** — чистота: низкий Precision = скрыли лишнее (over-masking), это не
  утечка, но портит читаемость.
- **strict vs relaxed** — разрыв показывает ошибки границ (взяли «Петров» вместо
  «Иван Петров»).
- **Micro / Macro** — общий итог vs среднее по типам (Macro не даёт «утопить»
  редкие типы).
- **Время** — медиана мс/текст по K повторам.
