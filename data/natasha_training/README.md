# Датасет для дообучения Natasha NER

Синтетический размеченный датасет для дообучения распознавания ПДн.
Генерируется автоматически — ручная разметка не требуется.

## Как сгенерировать заново

```bash
python3 generate_dataset.py
```

Скрипт использует фиксированный seed (42), поэтому результат воспроизводим.

## Структура

```
natasha_training/
├── generate_dataset.py   ← генератор (запускать отсюда)
├── train/                ← 700 примеров (70%)
│   ├── train.jsonl       ← спаны (для slovnet)
│   └── train.conll       ← BIO-теги (для большинства NER-фреймворков)
├── dev/                  ← 150 примеров (15%) — валидация при обучении
│   ├── dev.jsonl
│   └── dev.conll
└── test/                 ← 150 примеров (15%) — финальная оценка
    ├── test.jsonl
    └── test.conll
```

## Типы сущностей

PERSON, PHONE_NUMBER, EMAIL_ADDRESS, INN, SNILS, PASSPORT, DATE_OF_BIRTH, CREDIT_CARD

## Форматы

### JSONL (спаны) — для slovnet/Natasha
```json
{"text": "Клиент Петровой Ирине, ИНН 8367365762", "spans": [{"start": 7, "stop": 21, "type": "PERSON"}, {"start": 27, "stop": 37, "type": "INN"}]}
```

### CoNLL (BIO) — для spaCy, transformers и др.
```
Клиент	O
Петровой	B-PERSON
Ирине	I-PERSON
,	O
ИНН	O
8367365762	B-INN
```

## Качество данных (проверено автоматически)

- **Имена склоняются по всем 6 падежам** через pymorphy3 (с учётом пола)
- **595 уникальных вариантов** имён (склонения × форматы × регистр)
- **6 форматов ФИО**: ФИО, ФамИО, ИФ, ФИ, ИО, инициалы (И.П. Смирнов)
- **20% имён в нижнем регистре** — имитация неаккуратного ввода
- **Все ИНН проходят контрольную сумму ФНС** (169/169 валидны)
- **Все СНИЛС проходят контрольную сумму ПФР** (96/96 валидны)
- **5 шаблонов без ПДн** — чтобы модель не находила лишнего (защита от false positive)

## Baseline текущей модели на test (до дообучения)

| Тип | Recall |
|---|---|
| Все типы (regex) | 100% |
| PERSON (заглавная) | 99.0% |
| PERSON (строчная) | 93.5% |
| **Итого** | **99.1%** |

> На синтетике baseline уже высокий, т.к. данные следуют регулярным шаблонам.
> Главный прирост от дообучения ожидается на **реальных** чатах: опечатки,
> сленг, нестандартные конструкции — то, что трудно сгенерировать синтетически.
> Поэтому синтетику стоит дополнить выборкой реальных (деперсонализированных) текстов.
